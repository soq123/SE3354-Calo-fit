How to run:
1. Make sure Python 3 is installed on your device
2. Open terminal in the project root folder
3. Run: python data_collection/seed_data.py
4. It creates the database and fills it with realistic sample data


What it creates:
- 4 users (Yash, Sohaib, Dominic, Oliver)
- 38 meal entries across 7 days
- Unique meals each with their calories, protein, carbs, fats, and meal type


What it's used for:
- Testing daily calorie totals
- Testing weekly summaries
- Making sure each users data is kept separate
- Seeing what the app looks like with realistic data
