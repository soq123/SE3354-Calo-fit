Dashboard Redesign Plan
Overall Style
Redesign the app with a friendly, soft, playful CaloFit style instead of a sleek modern dashboard.
Use pastel colors, rounded cards, soft shadows, and a more welcoming layout.
Make the app feel like a friendly nutrition coach rather than just a calorie tracker.
Meal Cards
Do not use individual food images for every logged food.
Instead, use small icons based on the meal type:
Breakfast icon
Lunch icon
Dinner icon
Snack icon
Each meal card should show:
Meal type badge
Food name
Time/date
Calories
Protein, carbs, and fats
View button
Dashboard Layout
Add a welcoming header such as:
“Good afternoon!”
“Here’s your progress for today.”
Keep the meals displayed in clean cards on the left.
Keep today’s calorie/macro progress on the right.
Add a progress bar for daily calories.
Add small sections for:
Daily goal
Streak
Reminder
Tip of the day
Mascot Feature
Add a CaloFit mascot panel on the dashboard.
The mascot should appear next to a speech bubble.
The speech bubble should give personalized feedback based on the user’s progress.
Mascot Reactions

Use different mascot images/reactions depending on the user’s data:

Happy mascot:
User is within calorie goal
User is close to goal
User has a streak
Encouraging mascot:
User has not logged enough meals
User still has many calories remaining
Concerned mascot:
User went over calorie goal
User logged meals very late
User skipped meals
Supportive mascot:
User logs a negative mood
User has low consistency
User may need a reminder
Example Mascot Messages
“You did great today! You’re almost at your calorie goal. Just 101 kcal left!”
“Looks like you went over your goal today. No worries, try again tomorrow!”
“You haven’t logged any meals yet today. Don’t forget to fuel your body!”
“You’ve had late meals 3 days in a row. Try eating earlier for better sleep and digestion.”
“Your protein looks good today! Try adding more veggies to balance your meals.”
“Your mood seems low today. Try a balanced meal and take care of yourself.”
Main Differentiator

This feature makes CaloFit stand out because it is not just showing numbers. It gives users friendly, personalized feedback through a mascot coach that reacts to their eating habits, progress, and mood.
